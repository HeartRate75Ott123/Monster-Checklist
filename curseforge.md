# Monster Checklist

A monster checklist mod that integrates with Field Guide to track unlocked monsters, with milestone rewards and attribute boosts.

---

## Features

- **Monster Progress Tracking** — Auto-reads unlocked monster entries from Field Guide, paginated with sort by unlock status
- **Milestone Rewards** — Auto-grants attribute boosts on unlock thresholds (default 5/10/20/35/50)
- **Attribute Boost Pool** — Max health, speed, luck, knockback resistance, armor, toughness, reach, mining efficiency, dodge, crit, max energy (Paraglider required)
- **Built-in Textures** — No external resource pack needed

## Dependencies

- **[Field Guide](https://modrinth.com/mod/field-guide)** (required)
- **[Paraglider](https://modrinth.com/mod/paragliders)** (optional — max energy boost)

## Configuration

In-game: Esc → Mods → Monster Checklist → Config. Adjust the milestone threshold list there.

## Commands

- `/monsterchecklist add gift` — Test attribute boost grant (op level 2)
